Create a new session entry.

1. Look for existing `session-*.md` files in `01-sessions/` to find the highest session number.
2. Increment by one to get the new session number. If no session files exist, start at 1.
3. Read the template from `_templates/session.md`.
4. Copy the template and fill in:
   - The `session` field in the frontmatter with the new session number
   - The `date` field in the frontmatter with today's date (YYYY-MM-DD format)
   - The session number in the heading
   - Today's date in the heading
5. Save as `01-sessions/session-{number}.md`.
6. Confirm the file is ready for the user to fill in during or after play.
