Look up what the players know about: $ARGUMENTS

This is a **spoiler-free** command. Do NOT read the campaign source PDF.

1. Search through ALL of these directories for references to the topic:
   - `campaign/curse-of-strahd/01-sessions/` (session notes)
   - `campaign/curse-of-strahd/02-characters/` (party and NPC profiles)
   - `campaign/curse-of-strahd/03-key-events/` (major events)
   - `campaign/curse-of-strahd/04-places/` (locations)
   - `campaign/curse-of-strahd/05-quests/` (quest entries)
   - `campaign/curse-of-strahd/06-factions/` (factions and organizations)
   - `campaign/curse-of-strahd/07-lore/` (world lore and phenomena)
   - `campaign/curse-of-strahd/08-items/` (items)
2. Compile everything the party knows about the topic.
3. Clearly note where each piece of information came from (which session, event, character file, etc.).
4. Output the compiled lore directly to the chat.
